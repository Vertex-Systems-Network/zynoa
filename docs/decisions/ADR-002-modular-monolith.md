# ADR-002 — Modular monolith API + Temporal workers, not microservices

Date: decided in the build spec v2.0 (11 Oct 2026); recorded 2026-10-15 · Status: accepted · Source: `docs/spec/17_DECISIONS_AND_OPEN_QUESTIONS.md` §1

## Decision

Modular monolith API + Temporal workers, not microservices.

## Why

Team of 8–12; clear module boundaries keep a later split possible.

## Alternatives rejected

Microservices from day 1.
