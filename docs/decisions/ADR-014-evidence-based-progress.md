# ADR-014 — Evidence-based progress only

Date: decided in the build spec v2.0 (11 Oct 2026); recorded 2026-10-15 · Status: accepted · Source: `docs/spec/17_DECISIONS_AND_OPEN_QUESTIONS.md` §1

## Decision

Evidence-based progress only.

## Why

Core product promise; prevents "AI said done" failures.

## Alternatives rejected

AI self-reported progress.
