# ADR-001 — TypeScript monorepo (pnpm + Turborepo); Python only for media workers

Date: decided in the build spec v2.0 (11 Oct 2026); recorded 2026-10-15 · Status: accepted · Source: `docs/spec/17_DECISIONS_AND_OPEN_QUESTIONS.md` §1

## Decision

TypeScript monorepo (pnpm + Turborepo); Python only for media workers.

## Why

One language for web/API/agents; strong AI-agent familiarity; shared Zod contracts.

## Alternatives rejected

Polyglot microservices (too much overhead for team size).
