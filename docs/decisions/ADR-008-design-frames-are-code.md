# ADR-008 — Design Studio frames are code (React + Tailwind), not vector graphics

Date: decided in the build spec v2.0 (11 Oct 2026); recorded 2026-10-15 · Status: accepted · Source: `docs/spec/17_DECISIONS_AND_OPEN_QUESTIONS.md` §1

## Decision

Design Studio frames are code (React + Tailwind), not vector graphics.

## Why

Lossless design→code; reuses coding stack; avoids building Figma.

## Alternatives rejected

Vector editor (huge scope); Figma-only (dependency, API limits).
