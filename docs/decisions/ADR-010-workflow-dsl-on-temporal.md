# ADR-010 — Workflow engine = our JSON DSL interpreted on Temporal; UX inspired by n8n, no n8n code

Date: decided in the build spec v2.0 (11 Oct 2026); recorded 2026-10-15 · Status: accepted · Source: `docs/spec/17_DECISIONS_AND_OPEN_QUESTIONS.md` §1

## Decision

Workflow engine = our JSON DSL interpreted on Temporal; UX inspired by n8n, no n8n code.

## Why

Licence safety, deep integration with Systems, approvals, credits.

## Alternatives rejected

Embedding n8n (Sustainable Use License restrictions [VERIFY]), Zapier/Make (external dependency).
