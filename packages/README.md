# packages/

Shared libraries. Every package extends `@zynoa/config` for TypeScript (`tsconfig/base.json` or `tsconfig/library.json`) and ESLint (`eslint.config.js` → `export { default } from "@zynoa/config/eslint";`).

| Package                                                                                                             | State                 | Purpose                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config/`                                                                                                           | ✅ WU-P0-01, WU-P0-04 | Shared TSConfig + ESLint. Root `@zynoa/config` = feature flags (`createFlags`, `isEnabled`; edge/browser-safe). Server-only: `@zynoa/config/env` (`loadEnv`, fail-fast Zod env) and `@zynoa/config/flags/file` (`fileFlagSource`, `createFlagsFromEnv`) |
| `tokens/`                                                                                                           | ✅ WU-P0-00           | Design tokens for web, desktop and mobile                                                                                                                                                                                                               |
| `ui/`                                                                                                               | WU-P0-10              | Shared React components                                                                                                                                                                                                                                 |
| `db/`                                                                                                               | ✅ WU-P0-05           | Drizzle schema + migrations, `TenantRepository`/`tenantTransaction` (RLS scope), `enable_tenant_rls()`, `dbFlagSource`; integration suite runs in CI's `db-integration` job                                                                             |
| `model-gateway/`                                                                                                    | WU-P0-11              | ModelGateway interface + adapters                                                                                                                                                                                                                       |
| `contracts/`                                                                                                        | ✅ WU-P0-06           | Error codes + envelopes (spec 12 §2/§3), health schemas; grows with each API area                                                                                                                                                                       |
| `authz/`, `agents/`, `sandbox/`, `integrations/`, `workflow-engine/`, `systems-runtime/`, `billing/`, `test-utils/` | Later work units      | See `docs/spec/ENGINEERING-RULES.md` §3                                                                                                                                                                                                                 |

Only create a package when the work unit that needs it starts.
